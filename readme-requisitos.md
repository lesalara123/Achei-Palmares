# Requisitos iniciais

## Requisitos funcionais

### RF01 — Acesso público

O consumidor deve conseguir acessar a plataforma sem criar uma conta.

### RF02 — Login administrativo

O sistema deve disponibilizar um login exclusivo para o administrador do projeto.

### RF03 — Gerenciamento de estabelecimentos

O administrador deve conseguir cadastrar, consultar, editar e excluir estabelecimentos.

### RF04 — Gerenciamento de categorias

O administrador deve conseguir cadastrar, consultar, editar e excluir categorias.

### RF05 — Gerenciamento de produtos e serviços

O administrador deve conseguir cadastrar, consultar, editar e excluir produtos ou serviços vinculados a um estabelecimento.

### RF06 — Pesquisa por nome

O consumidor deve conseguir pesquisar por nome de produto ou serviço.

### RF07 — Filtro por categoria

O consumidor deve conseguir filtrar os resultados por categoria.

### RF08 — Exibição dos resultados

O sistema deve exibir os estabelecimentos relacionados ao produto ou serviço pesquisado.

### RF09 — Exibição de informações

O sistema deve permitir consultar nome, endereço, horário de funcionamento e formas de contato do estabelecimento.

### RF10 — Acesso à localização

O sistema deve disponibilizar a localização do estabelecimento a partir do endereço cadastrado, inicialmente por meio de mapa ou link de navegação.

## Requisitos não funcionais

### RNF01 — Plataforma

O sistema deve funcionar como aplicação web acessível por navegador.

### RNF02 — Segurança

As operações administrativas devem exigir autenticação.

### RNF03 — Restrição de acesso

Consumidores não devem ter acesso às funções de gerenciamento.

### RNF04 — Usabilidade

A pesquisa deve ser simples, clara e adequada para usuários sem conhecimento técnico.

### RNF05 — Manutenibilidade

A documentação e o código devem ser organizados por responsabilidade.

### RNF06 — Responsividade

A interface deve se adaptar a computadores e dispositivos móveis, mesmo que não seja criado um aplicativo mobile inicialmente.

## Fora do escopo inicial

- Cadastro de consumidores;
- Cadastro público de comerciantes;
- Avaliações e comentários;
- Pagamentos e pedidos;
- Entregas;
- Chat;
- Controle de estoque em tempo real;
- Aplicativo mobile nativo;
- Geolocalização obrigatória do consumidor.
