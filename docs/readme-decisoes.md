# Registro de decisões do projeto

## DEC-001 — Aplicação web

**Decisão:** iniciar o projeto como uma aplicação web.

**Motivo:** permite acesso por navegador e evita a necessidade de desenvolver um aplicativo mobile neste primeiro momento.

## DEC-002 — Acesso administrativo único

**Decisão:** iniciar com um login exclusivo para o administrador do projeto.

**Motivo:** reduz a complexidade inicial e centraliza a manutenção das informações enquanto o sistema está sendo validado.

## DEC-003 — Pesquisa sem cadastro

**Decisão:** consumidores poderão pesquisar sem criar conta.

**Motivo:** a busca deve ser rápida e acessível, sem exigir etapas desnecessárias.

## DEC-004 — Pesquisa por nome e categoria

**Decisão:** os critérios iniciais serão o nome do produto ou serviço e a categoria.

**Motivo:** atende ao objetivo principal do sistema sem tornar a primeira versão complexa.

## DEC-005 — Localização por endereço

**Decisão:** a primeira versão deverá exibir o endereço e permitir acesso à localização, mas não dependerá da localização automática do consumidor.

**Motivo:** a localização automática exige permissão do navegador e não é essencial para validar o fluxo principal de busca.

## DEC-006 — Documentação separada

**Decisão:** assuntos diferentes serão documentados em arquivos diferentes.

**Motivo:** facilita a manutenção, a consulta e o acompanhamento das alterações do projeto.

## Próximas decisões

As seguintes decisões ainda deverão ser registradas antes da implementação:

- Tecnologias do frontend e backend;
- Tecnologia do banco de dados;
- Serviço de mapas ou estratégia de geocodificação;
- Forma de publicação da aplicação;
- Estratégia de testes.
